# دار التألق للعطور — موقع مجاني

## تشغيل الموقع
افتح `index.html` مباشرة في المتصفح للتصميم، أو ارفعه إلى GitHub Pages.

## تعديل وإضافة العطور
كل البيانات موجودة في `perfumes.json`.
كل عطر له:
- name: اسم العطر
- brand: الماركة
- description: الوصف الإعلاني
- notes: النوتات
- prices: أسعار العبوات

الأسعار الافتراضية الموضوعة حالياً: 200 / 300 / 500 / 700 / 1000 دج.
يمكن تغييرها لأي عطر.

## نشره مجاناً على GitHub Pages
1. افتح github.com وأنشئ حساباً.
2. أنشئ Repository جديداً مثلاً: dar-talaq-parfums
3. ارفع `index.html` و `perfumes.json`.
4. من Settings > Pages اختر Deploy from branch ثم main ثم /(root).
5. سيعطيك GitHub رابطاً من نوع:
   https://USERNAME.github.io/dar-talaq-parfums/

بعد النشر، أي تعديل على `perfumes.json` ثم Commit سيحدّث الموقع.

## ملاحظة الصور
النسخة الحالية تستخدم رسماً بصرياً خفيفاً للزجاجة + صورة رمزية للنوتات حتى يبقى الموقع سريعاً ولا يعتمد على صور خارجية. يمكن لاحقاً استبدالها بصور المنتجات الحقيقية لكل عطر.
